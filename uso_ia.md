# Declaración de Uso de Inteligencia Artificial

## 1. IA usada
- Gemini (Asistente de Inteligencia Artificial).

## 2. Modelo
- Google Gemini LLM.

## 3. Prompts realizados
- "Ayúdame con la estructura de rutas y la navegación con `react-router-dom` para un portafolio web en React y Vite."
- "Ayúdame a seguir estrictamente este wireframe para la maquetación de Inicio, Sobre Mí, Habilidades, Proyectos y Contacto.[adjunta imagen]"
- "Cómo estructurar el componente de formulario de contacto con control de estado en React y validaciones de correo."
- "Por qué no funciona esta imagen en React con Vite y cómo importarla desde la carpeta `assets`."
- "Cómo aplicar estilos en CSS global (`index.css`) en lugar de mantener tanto código inline en los componentes JSX."
- Me ayudo siempre a la hora cuando aparecia errores al ejecutar `npm run dev`

## 4. Outputs
- Código base para la configuración de rutas con `<BrowserRouter>`, `<Routes>` y `<Route>` en `main.jsx` y `App.jsx`.
- Estructura y maquetación de los componentes de página (`Inicio.jsx`, `SobreMi.jsx`, `Habilidades.jsx`, `Proyectos.jsx`, `Contacto.jsx`) y reutilizables (`TarjetaProyecto.jsx`, `Layout.jsx`).
- Explicaciones técnicas y soluciones para resolver errores de compilación de Vite (importaciones de librerías, ajuste de rutas en `src/src` y nombres de archivos).
- Hoja de estilos global en `index.css` utilizando variables CSS para la paleta de colores morados oscuros y utilidades responsivas.

## 5. Ajustes
- Se adaptó todo el contenido visual y descriptivo para reflejar mi perfil real de estudiante de Ingeniería Civil Informática y desarrolladora Frontend.
- Se reestructuró la ubicación de los componentes y archivos dentro de la carpeta `src/` para mantener una arquitectura limpia y corregir los fallos de rutas relativas.
- Se personalizaron las imágenes y tarjetas de proyectos importando recursos locales desde `src/assets/` con propiedades `object-fit: cover`.

## 6. Reflexión crítica
El uso de la Inteligencia Artificial durante este proyecto fue una herramienta sumamente valiosa para agilizar la maquetación inicial, acelerar el diseño de componentes en React y diagnosticar de forma inmediata errores comunes de compilación y enrutamiento en Vite. Sin embargo, no reemplazó el criterio técnico ni la toma de decisiones: fue indispensable revisar y comprender cada bloque de código, ajustar las referencias de importación de archivos y adaptar los estilos visuales para garantizar que el resultado final fuera completamente fiel a los wireframes y a los requerimientos académicos exigidos.
